# ATHEER — شات P2P + ستوريز + مكالمات (Kotlin / Compose)

| الحاجة | بتتعمل إزاي |
|---|---|
| الدخول | رقم الهاتف، والتأكيد عن طريق **بوت تيليجرام** (مجاني، من غير SMS) |
| الشات | **P2P** (WebRTC DataChannel) + تشفير ECDH/AES-GCM + تخزين محلي على الجهاز |
| لو الطرف التاني أوفلاين / التطبيق مقفول | الرسالة المشفّرة تتحط في صندوق مؤقت (`mailbox`) وتتبعت إشارة FCM، والمستلم يسحبها ويتمسح من السيرفر |
| المكالمات | صوت وفيديو P2P بـ WebRTC، وإشعار مكالمة بشاشة كاملة حتى والتطبيق مقفول |
| الصور والستوريز | على تيليجرام (عن طريق Edge Function، التوكن مش في التطبيق) |
| البناء | GitHub Actions (APK) |

> **ملاحظة صريحة:** P2P الخالص مستحيل يوصّل لجهاز مقفول لأن الجهاز مش بيسمع. علشان كده في صندوق مؤقت مشفّر: السيرفر بيشوف نص مشفّر بس، ومبيحتفظش بحاجة بعد ما توصل.

## 1) Supabase
- شغّل `supabase/migrations/20261008000000_init.sql` (SQL Editor أو `supabase db push`).
- **مفيش حاجة تتفعّل في Authentication ← Providers.** الحسابات بتتعمل من الدالة بإيميل داخلي مشتق من الرقم (Email provider لازم يكون شغّال، وتأكيد الإيميل مش مطلوب).
- ادفع الدوال: `telegram-storage` و `tg-auth` (**بدون JWT**، الإعداد في `config.toml`) و `push`.

## 2) تيليجرام
1. `@BotFather` ← بوت جديد ← التوكن + الـ username.
2. قناة **خاصة** والبوت أدمن فيها ← الـ chat id (`-100…`) لتخزين الملفات.
3. الأسرار: `TELEGRAM_BOT_TOKEN` `TELEGRAM_BOT_USERNAME` `TELEGRAM_CHAT_ID` `TELEGRAM_WEBHOOK_SECRET` (نص عشوائي طويل) `AUTH_PW_SECRET` (نص عشوائي طويل، **متغيّرهوش بعد كده** وإلا الحسابات تتقفل).
4. الـ webhook بيتسجّل من workflow `supabase.yml` أو يدويًا:
   `curl "https://api.telegram.org/bot<TOKEN>/setWebhook" -d url="https://<REF>.supabase.co/functions/v1/tg-auth" -d secret_token="<SECRET>"`

## 3) إشعارات الرسايل والمكالمات والتطبيق مقفول (Firebase، مجاني)
1. مشروع Firebase ← أضف تطبيق Android بالـ package `com.binarybeast.chatapp` ← نزّل `google-services.json`.
2. Project settings ← Service accounts ← Generate new private key ← الملف ده هو سر `FIREBASE_SERVICE_ACCOUNT` (للدالة `push`).
3. لو `app/google-services.json` مش موجود التطبيق بيتبني عادي من غير إشعارات.
4. على بعض الأجهزة (Xiaomi / Huawei / Oppo) لازم المستخدم يسمح بـ Autostart وإلغاء تحسين البطارية، وإلا النظام بيقتل الإشعارات.

## 4) GitHub Actions
ارفع المشروع على ريبو، وضيف **Secrets** (Settings ← Secrets and variables ← Actions):

| Secret | الاستخدام |
|---|---|
| `SUPABASE_URL`, `SUPABASE_ANON_KEY` | بيتحطوا في التطبيق وقت البناء (مفتاح anon/publishable بس، **مش service_role**) |
| `GOOGLE_SERVICES_JSON_B64` | اختياري: `base64 -w0 google-services.json` |
| `TURN_URL`, `TURN_USER`, `TURN_PASS` | اختياري: TURN للشبكات الصارمة |
| `KEYSTORE_B64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` | لـ APK موقّع عند عمل tag زي `v1.0.0` |
| `SUPABASE_ACCESS_TOKEN`, `SUPABASE_DB_PASSWORD`, `SUPABASE_PROJECT_REF` + أسرار تيليجرام وFirebase فوق | لـ workflow نشر Supabase (يدوي بس) |

- `android.yml`: على كل push يبني `app-debug.apk` ويرفعه Artifact. على tag `v*` يبني النسخة الموقّعة وينشرها في Releases.
- `supabase.yml`: تشغيل يدوي (Run workflow): migrations + دوال + أسرار + webhook تيليجرام.
- مفيش `gradle-wrapper.jar` في الريبو، الـ workflow بينزّل Gradle 8.9 بنفسه. لو هتبني من Android Studio هو بيعمله لوحده.

## حدود لازم تعرفها
- **ماتجمّعش (compile) عندي**؛ متوقع تظبط تفاصيل صغيرة عند أول Build.
- التشفير ده ECDH ثابت + AES-GCM، **مش Signal Protocol**: مفيش forward secrecy ولا تحقق من هوية المفاتيح (السيرفر نظريًا يقدر يبدّل المفتاح العام).
- الرسايل محفوظة **على الجهاز بس**: تسجيل الخروج أو مسح بيانات التطبيق أو ضياع الجهاز = ضياع الرسايل (مفيش نسخة احتياطية).
- أي مستخدم مسجّل يقدر يدوّر على أي رقم، وبيشوف الاسم والصورة والحالة.
- سبام: أي مستخدم يقدر يكتب في `mailbox` لأي مستلم، من غير حد أقصى.
- ستوريز الفيديو بتترفع بس مش بتتشغّل في العارض لسه (محتاج ExoPlayer).
- إعدادات الخصوصية بتتخزن لكن مش متنفّذة بالكامل لسه. الشات الجماعي مش موجود.
- مفيش TURN افتراضي: على بعض شبكات الموبايل P2P مش هيتوصّل لحد ما تضيف TURN.

## تحديث: المحرر والمتصفح والإعدادات

- **محرر صور/فيديو مدمج**: قص/تدوير/قلب، فلاتر، سطوع/تباين/تشبّع، رسم، نصوص وإيموجي. الفيديو: قص (trim)، كتم، فلاتر، نص محروق، ضغط. بيشتغل قبل الإرسال في الشات وقبل نشر الستوري (الفيديو للستوري حد أقصى 30 ثانية).
- **متصفح مدمج**: بيفتح الروابط من الشات (أو خارجي حسب الإعداد)، شريط عنوان، رجوع/أمام، وضع سطح المكتب، مشاركة/نسخ.
- **إعدادات**: الحساب، الخصوصية، الشات، الإشعارات، التخزين، المكالمات، المتصفح، المحظورين.
- **حدود مهمة**: أقصى حجم ملف 20 ميجا (حد تيليجرام لتنزيل getFile). جودة "عالية" للصور بتترفع كـ document (`image_hq`). الملفات العادية بتتبعت لكن مفيش فتح مباشر ليها لسه.
- الكاميرا بتستخدم FileProvider (`res/xml/file_paths.xml`).
- **الكود لم يتم تجميعه (compile) بعد**: شغّل workflow الـ Android وهتظهر أي أخطاء بناء لو فيه.

## بدون Firebase (الافتراضي)
التطبيق بيشغّل خدمة `KeepAliveService` (foreground، إشعار صامت) بتفضل متصلة بـ Supabase Realtime وبتسحب الصندوق المشفّر كل دقيقتين، فالرسايل والمكالمات بتوصل والتطبيق مقفول من غير أي خدمة جوجل. بتشتغل تاني بعد إعادة تشغيل الجهاز. فعّل من الإعدادات > الإشعارات وامنح «بدون قيود» للبطارية (في أجهزة شاومي/سامسونج/أوبو ضروري). Firebase لسه اختياري لو ضفت `google-services.json`.

## كابشن التخزين على تيليجرام
كل ملف (بروفايل / ستوري / ميديا شات) بيتخزن في قناة تيليجرام ومعاه كابشن بيبنيه السيرفر: اسم المستخدم ورقمه و user_id، الغرض (بروفايل/ستوري/شات)، النوع والـ MIME والحجم، وقت السيرفر (UTC) ووقت الجهاز والمنطقة الزمنية. هوية المستخدم بتتاخد من الـ JWT مش من العميل، فمينفعش تتزوّر. لازم تعمل redeploy لدالة `telegram-storage`.

## سيرفر Supabase الجاهز
المشروع `gvrqgcryszvubsuvlgid` اتجهّز: الجداول + RLS + Realtime + الدوال التلاتة (`tg-auth`, `telegram-storage`, `push`). البروفايل بتنشئه دالة `tg-auth` (من غير trigger على auth.users). لسه عليك الأسرار (Telegram + اختياريًا Firebase) وتسجيل الـ webhook.

## ميزات الشات الجديدة
ضغطة مطوّلة على أي رسالة: تفاعل (👍❤️😂😮😢🙏)، رد (مع اقتباس)، نسخ، تعديل (رسايلك النصية)، حذف (عندي بس / عند الطرفين). بحث داخل المحادثة من أيقونة 🔍. كلها بتتبعت كرسايل تحكّم مشفّرة (نفس مسار P2P/الصندوق) ومبتتخزنش على السيرفر. قاعدة الرسايل المحلية اتحدّثت للإصدار 2 بـ migration من غير مسح الرسايل القديمة.

## ميزات إضافية
- **رسائل صوتية:** زر المايك لما الخانة فاضية، تسجيل AAC/m4a، وبتتخزن على تيليجرام زي باقي الميديا (النوع `audio`) وبتتشغّل من الشات.
- **«بيكتب…»:** بيتبعت على قناة P2P المفتوحة بس (مفيش حاجة بتروح السيرفر)، فبيظهر لما الاتصال P2P يكون شغال.
- **تثبيت وأرشفة المحادثات:** ضغطة مطوّلة على المحادثة؛ أيقونة الأرشيف فوق بتعرض المؤرشفة. محلية على الجهاز.

## المجموعات (من غير سيرفر رسايل)
- كل رسالة بتتشفّر **لكل عضو لوحده** (ECDH + AES-GCM) وبتتبعت P2P لو القناة مفتوحة، وإلا عن طريق الصندوق المشفّر + إعادة محاولة بعد 4 ثواني من غير تأكيد. السيرفر عمره ما يشوف نص أو أسماء مجموعات.
- بيانات المجموعة (الاسم/الأعضاء/المؤقّت) متخزّنة محليًا عند كل عضو، والأدمن بس هو اللي يبعت `gmeta` وغيره بيتجاهل. لو الأدمن خرج، أول عضو متبقي بياخد الأدمن.
- **استطلاعات:** كل صوت رسالة تحكّم مشفّرة لكل الأعضاء، الصوت الواحد لكل عضو.
- **مسح تلقائي:** الأدمن بيحدد (معطّل/ساعة/يوم/أسبوع) وكل جهاز بيمسح رسايل المجموعة محليًا بعد المدة.
- حدود: التفاعل بيعرض آخر تفاعل بس، ومفيش مكالمات جماعية، وعضو أوفلاين لازم يكون فتح التطبيق مرة علشان مفتاحه العام يتنشر. القاعدة المحلية اتحدّثت للإصدار 3 بـ migration.

## ميزات تانية (دفعة 3)
- **الرسائل المحفوظة** 🔖: محادثة مع نفسك محلية بالكامل، و«حفظ» من قايمة الضغطة المطوّلة على أي رسالة.
- **تحويل الرسائل** لأي محادثة (نص/صورة/فيديو/صوت/ملف؛ الاستطلاعات مبتتحوّلش).
- **كتم محادثة** (ضغطة مطوّلة على المحادثة) فلا تيجي إشعارات منها.
- **قفل التطبيق بـ PIN** (الإعدادات > الخصوصية): بيتقفل عند الفتح أو الرجوع بعد 15 ثانية، ومبيحجبش مكالمة شغّالة. الـ PIN متخزّن مملّح ومتهّش على الجهاز، ومفيش استرجاع لو اتنسي.
- **لون التطبيق** (الإعدادات > الشات): ATHEER (افتراضي) / بنفسجي / أخضر / برتقالي / أحمر.
- **«متصل الآن»** تحت اسم الشخص لما قناة P2P معاه تكون مفتوحة.

## تحسين استهلاك الداتا في المجموعات
- **نداء واحد للصندوق** لكل الأعضاء (insert جماعي) بدل طلب لكل عضو.
- **نداء FCM واحد** (`to_many`) لكل الأعضاء، ومبيتبعتش لرسايل التحكّم (تفاعل/تصويت/تعديل/تغيير أعضاء) لأنها مش محتاجة تصحية.
- **مفيش فتح اتصالات P2P جديدة** للمجموعات (كل اتصال بيكلّف عشرات صفوف signaling)؛ بتستخدم الاتصالات المفتوحة فقط وإلا الصندوق المشفّر.
- الميديا بتترفع **مرة واحدة** على تيليجرام والأعضاء بيشاركوا نفس الـ file_id.
- **وضع توفير البيانات** (الإعدادات > التخزين): تحميل يدوي للصور، رفع بأقل جودة، مكالمات منخفضة الجودة.
- **تصدير المحادثة** كنص (آخر 2000 رسالة) من قايمة المحادثة.
- لازم تعمل redeploy لدالة `push` (اتنشرت على المشروع بالفعل).


## اليوزر نيم والستوريز والحدود (تحديث)
- **اليوزر نيم**: بعد أول دخول بتظهر شاشة تختار الاسم واليوزر نيم (`a-z` وأرقام و `_`، 3–20، فريد). تقدر تغيّره من الحساب، وتدوّر بيه (`@name`) أو بالرقم في محادثة جديدة. بيظهر في كابشن تيليجرام.
- **الستوريز**: أقصى 5 نشطة لكل مستخدم (مفروضة في الداتابيز بـ RLS)، والمستخدم بيحدد المدة (ساعة … 7 أيام أو أي رقم لحد 720 ساعة). مفيش حد لطول الفيديو.
- **شلنا الحدود**: الملفات الكبيرة بتتقسّم تلقائي لقطع 15MB على تيليجرام وتتجمّع عند التنزيل (الحد العملي ذاكرة الجهاز ~400MB)، حد جودة الفيديو اتشال، الاستطلاعات لحد 20 اختيار، والاسم/الحالة أطول.

## الخصوصية (تحديث)
- **رقم الهاتف مخفي عن كل المستخدمين** على مستوى الداتابيز (column privileges)؛ البحث بالرقم بيمشي عن طريق دالة `find_user_by_phone` بتحترم إعداد «ممكن حد يلاقيني برقم تليفوني».
- إعدادات جديدة: إخفاء «بيكتب…»، تجاهل الغرباء، مين يضيفني في مجموعات (الكل/اللي ليا معاهم محادثة/محدش)، قفل تلقائي (فوري/15ث/دقيقة/5د)، إخفاء آخر رسالة في القايمة، إخفاء اسم المرسل ومحتوى الإشعار، مسح كل الرسايل من الجهاز.
- **التحقق من التشفير**: من قايمة المحادثة (⋮) رقم أمان مشترك تقارنه مع الطرف التاني.

## القنوات (تحديث)
- تبويب «القنوات»: إنشاء قناة (اسم + @رابط + وصف)، بحث بالاسم أو الرابط، اشتراك/إلغاء اشتراك، كتم القناة.
- صاحب القناة بينشر نص/صور/فيديو (الميديا على تيليجرام)، ويحذف منشوراته أو القناة كلها.
- المنشورات بتتخزن في Supabase (`channels`, `channel_members`, `channel_posts`) بصلاحيات RLS: بس صاحب القناة ينشر ويحذف، والمشترك يقرأ. **القنوات عامة وغير مشفّرة end-to-end** (عكس الشات).
- منشور واحد على السيرفر مهما كان عدد المشتركين، وإشعار فوري عبر Realtime (والتطبيق شغّال أو الخدمة الخلفية).

## ميديا مرة واحدة / مؤقّتة
- قبل إرسال أي صورة أو فيديو أو رسالة صوتية بتظهر نافذة: **عادي** | **👁 مرة واحدة** | **⏱ مؤقّت** (10ث / 30ث / دقيقة / ساعة / 24 ساعة أو أي عدد ثواني).
- مرة واحدة: بتتشال أول ما المستلم يقفلها. مؤقّت: العدّ بيبدأ من أول فتح، والعارض بيتقفل لوحده والرسالة بتتشال بعد انتهاء المدة (حتى لو التطبيق مقفول، بتتنضّف كل دقيقة).
- أثناء العرض لقطات الشاشة مقفولة (FLAG_SECURE)، والتحويل والحفظ ممنوعين. عند المرسل بتظهر 🔒 من غير محتوى.
- حد صريح: ده حماية على مستوى التطبيق؛ الملف الأصلي بيفضل في قناة تخزين تيليجرام بتاعتك، ومستلم بنسخة معدّلة من التطبيق أو بتصوير الشاشة بكاميرا تانية يقدر يلتقطه.

## تخزين الميديا (زي تيليجرام)
الميديا مبتتحفظش في المعرض ولا الملفات: كاش مؤقت جوه التطبيق بحد أقصى (100MB/500MB/2GB/من غير حد) ومسح تلقائي بعد (يوم/7/30/أبدًا) + «مسح الكاش الآن». الأصل على السحابة (تيليجرام).

## ميزات جديدة
- **إيصالات القراءة (✓✓ زرقا) والفتح** (اتفتحت ✅ للميديا مرة واحدة/المؤقتة) مع زرار لقفلها من الخصوصية.
- **مسح تلقائي** لكل محادثة عادية (ساعة/24س/7 أيام/30 يوم) · **إرسال صامت** (من غير إشعار) · **رسايل مجدولة** · **نجمة للرسايل** وعرض المميّزة بس.

## مراجعة أمان (ما اتقفل)
- الداتابيز: رقم الهاتف و tg_user_id مقفولين عن الغير، البحث بالرقم عبر دالة بتحترم `discoverable` وفيها حد 120 محاولة/ساعة، القراءة محتاجة بروفايل، حدود حجم (رسايل 64KB، إشارات 32KB، البروفايل، المنشورات)، منع إغراق (600 رسالة/د، 300 إشارة/د، 30 منشور/د)، حد رفع 300 قطعة/ساعة لكل مستخدم.
- الدوال: تحقق من file_id، رؤوس nosniff/CSP، رسايل خطأ عامة، تنضيف وسقف على طلبات الدخول، تحذير في رسالة البوت.
- التطبيق: تشفير الرسايل مربوط باتجاه المرسل→المستلم (AAD)، PIN بـ PBKDF2 + قفل تدريجي بعد 5 محاولات، منع النسخ الاحتياطي واستخراج البيانات، منع cleartext، BootReceiver غير مصدّر، التحقق من معرّفات الملفات والأطوال في الرسايل الواردة، إخفاء الإشعارات على شاشة القفل لما المعاينة مقفولة.
- **متبقّي (لازم تعرفه):** ميديا الشات مرفوعة على تيليجرام غير مشفّرة end-to-end؛ مفيش forward secrecy؛ القنوات عامة؛ minify مقفول في release؛ ولازم تقفل «Allow new users to sign up» من Supabase Auth.

## الهوية البصرية — Liquid Neon (تحديث الديزاين)
- **داكن:** أسود نقي + كحلي (surfaces) + نيون (سماوي/ليموني/وردي). **فاتح:** عاجي (سمني) + الألوان المقابلة للنيون (قرمزي/بنفسجي/زمردي). الألوان في `ui/Theme.kt` (`Brand` و`ACCENTS`) — تعديلها بسطر واحد.
- **أزرار دايرية** (`GlassCircleButton`) وشرائط عائمة (`GlassTopBar` علوي و`FloatingNavBar` سفلي) على شكل جزر.
- **زجاج سائل (Liquid Glass)** في `ui/Glass.kt`: تدرّج شفاف + لمعة علوية + حافة مضيئة + ظل ملوّن. ملحوظة: ده محاكاة؛ blur حقيقي للخلفية محتاج مكتبة زي Haze.
- **خلفية الشات** (`ChatWallpaper`): رسومات SVG متكررة / أورورا / نقط / سادة — من الإعدادات ← خلفية الشات.
- **كل الأيقونات SVG** في `design/icons/*.svg`؛ بعد أي تعديل شغّل `python3 tools/gen_icons.py` عشان يتولّد `ui/AIcons.kt`.
